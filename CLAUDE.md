# Claude Instructions for SharpCrafters.Backstage

## Merging changes from Metalama 2026.1

Changes made to the `Metalama.Backstage` folder of Metalama 2026.1 are merged into this repository through the
`develop/2026.1` branch. Read [docs/upstream-merge.md](docs/upstream-merge.md) before such a merge. It records the last
merged Metalama commit and describes the procedure.
