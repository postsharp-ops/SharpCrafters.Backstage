The `Metalama.Backstage.Tools` package is not meant to be referenced in user projects.

It carries the Backstage tools of Metalama as zipped executables: the worker, which serves the local setup pages and uploads telemetry, and the Windows notifier, which shows toast notifications. Metalama extracts them on the machine of the user when they are needed.
